# Домашнее задание №2. Объектно-ориентированное программирование. Тестирование. Работа с Git

Реализованы классы Ingredient, Recipe, ShoppingList, DietaryRecipe с помощью ООП и тесты к ним на основе pytest



## Использование

### Установка 

```bash
git clone <ваш-репозиторий>
cd <папка>
pip install -r requirements.txt
pytest
```

Код выше показывает как сохранить файлы проекта к себе на компьютер и запускать тесты. Выполнять код можно также непосредственно из .py файликов
